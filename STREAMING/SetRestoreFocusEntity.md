## SET_RESTORE_FOCUS_ENTITY

```c
// 0x0811381EF5062FEC
void SET_RESTORE_FOCUS_ENTITY(Entity p0);
```

```
Special case for player switch termination. Restores streaming focus to a specific ped rather than the default current player ped. Old hash 0xE35FCEF2127AFCCF.
```

## Parameters
* **p0**: Entity to restore focus to.
