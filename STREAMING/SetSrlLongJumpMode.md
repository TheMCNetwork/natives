## SET_SRL_LONG_JUMP_MODE

```c
// 0x20C6C7E4EB082A7F 0xA6459CAA
void SET_SRL_LONG_JUMP_MODE(BOOL p0);
```

```
Enables or disables Long Jump Mode for cutscenes. Enable when cutscene involves camera cuts across long distances. Call right after PREFETCH_SRL. Old hash 0xA694A53A397FC676.
```

## Parameters
* **p0**: TRUE to enable long jump mode, FALSE to disable.
