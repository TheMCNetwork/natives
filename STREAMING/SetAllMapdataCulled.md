## SET_ALL_MAPDATA_CULLED

```c
// 0x4E52E752C76E7E7A 0xA07BAEB9
void SET_ALL_MAPDATA_CULLED(Any p0);
```

**This native does absolutely nothing, just a nullsub**

```
Sets all map data culled or not. Useful to cull map data during UI screens for multiplayer etc. Old hash 0x4C6CBCFDD1730E10.
```

## Parameters
* **p0**: TRUE to cull all map data, FALSE to undo.
