## IS_SWITCH_TO_MULTI_FIRSTPART_FINISHED

```c
// 0x933BBEEB8C61B5F4 0x74C16879
BOOL IS_SWITCH_TO_MULTI_FIRSTPART_FINISHED();
```

```
Returns true if ascent phase of SP to MP switch finished, safe to show MP menu etc. Pair with SWITCH_TO_MULTI_FIRSTPART and SWITCH_TO_MULTI_SECONDPART. Old hash 0x5E9EC8EEA03BCEC7.
```

## Return value
True if first part ascent finished, else false.
